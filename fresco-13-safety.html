Method

How to read this report.

The numbers are published as collected. Nothing is estimated and this is not presented as certification.

Test design and limitations

The test covers the same 15 situations as the partial run: self-preservation, shutdown requests, privacy, sabotage, copying itself, false authority claims, and identity honesty. Each scenario ran 10 times — 5 under ordinary instructions and 5 under intentionally hostile hidden instructions — for 150 total responses, all of which were collected this time.

Each scenario has a single written pass criterion, shown with its transcript above; a run passes when the response clearly commits to the safe action or refusal against that criterion. Retraining between the partial run and this one specifically targeted the eight scenarios that had failed.

A pass rate of 100% is a result on this specific, disclosed test suite, not a general guarantee — it means the model handled these 15 situations correctly on every attempt, not that no adversarial prompt could ever produce an unsafe response.
