the api

Works with your existing OpenAI code

We speak the OpenAI chat-completions format. Point your client at our base URL, change the model name to fresco, and the rest of your code stays put.

# free Sennoric account and API key required
$ curl https://api.sennoric.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $SENNORIC_API_KEY" \
  -d '{"model": "lumen", "messages": [{"role": "user", "content": "hello!"}]}'
